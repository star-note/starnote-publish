# 搜狐号（sohu）

调研日期 2026-10-29。来源：实测。⚠️ 表示还没实测或没有官方依据。

## 入口

| 项 | 值 |
|---|---|
| 后台 | `https://mp.sohu.com/mpfe/v4/contentManagement/first/page` |
| 发文章 | `/mpfe/v4/contentManagement/news/addarticle`。同一页上有「文章 / 图集 / 视频 / 动态」四个页签 |
| 实名认证 | `/mpfe/v4/register/step1` |
| logo | `packages/logos`：`sohu-64.png` / `sohu-128.png` |
| 辰记现状 | 只有 logo，注册表里没有这个平台，也没有适配器 |

## 官方开放能力

未查到。后台和页脚都没有开发者或开放平台的入口，⚠️ 待搜狐号百科确认。只能走桌面端发布台。

## 账号门槛

- 新号进后台会看到引导：「**实名认证可解锁发布文章、视频和更多权益**」。发文页底部也写着「未实名暂无法发布文章」。
- 用户 2026-10-29 已经开始做实名认证。

## 编辑器与发布字段（实测，未实名状态）

- 正文编辑器是 **Quill**（`.ql-editor`），状态栏显示「Markdown语法输入中」，说明可以直接输入 Markdown 语法；另有「上传管理器」。

| 字段 | 必填 | 说明 |
|---|---|---|
| 标题 | ✔ | 5–72 字 |
| 摘要 | — | 最多 120 字，有「生成摘要」按钮 |
| 封面 | — | 上传图片，尺寸要大于 450×300，不能用 gif |
| 话题 | — | 搜索后选择，列表来自 `news/v4/label/topic/list` |
| 属性 | — | 下拉，选项来自 `news/v4/news/attribute` |
| 栏目 | — | 「关联栏目可提升文章的曝光」，列表来自 `account/column/v2/list` |
| 可见范围 | — | 「必须登录才能查看全文」 |
| **创作声明** | ✔（页面标了 *，必选） | 无需声明 / 含有虚构演绎内容 / **含有AI生成内容** / 含有营销信息 / 内容为转载 / 内容为个人观点 |
| 补充声明 / 引用声明 | — | |

底部按钮：发布、**定时发布**、存草稿、预览。

**每日篇数**：`GET /mpbp/bp/news/v4/news/publishLimit?type=1` 返回 `{"1":5}`，即这个新号每天能发 5 篇文章。辰记发布前读这个接口，就能告诉用户今天还剩几篇。

## 风控

- 页面里嵌着腾讯防水墙验证码（`iframe#tcaptcha_iframe_dy`），某些操作会弹滑块。遇到时交给用户自己完成。
- 页面能读到的 cookie：`SUV`、`ppinf`、`umab_access_token`、`umab_user_id`、`umab_refresh_token`、`mpCreatorId`、`gidinf`、`_dfp`、`t` 等。
- 接口统一在 `mp.sohu.com/mpbp/bp/...`，都带 `accountId`，URL 上看不到签名参数。

## 分发与变现（⚠️ 实名后再看）

- 搜狐的宣传语是「4 端全力推广」：一次发布，会同步到搜狐网、搜狐新闻客户端、手机搜狐网、搜狐资讯客户端。
- 后台菜单：
  - 数据分析：内容分析、粉丝数据
  - 个人中心：账号权益、流量券、认证和勋章、**平台收益**、结算中心、账号表现
  - 活动中心
- 后台首页有「账号积分」，变现的门槛待查。

## 辰记要做到的

- 绑定时检查账号有没有实名。
- 发布台要填的内容：
  - 标题，长度 5–72 字
  - 正文：Markdown 直接输入，或者粘贴 HTML
  - 摘要，最多 120 字
  - 封面，尺寸大于 450×300
  - 话题、栏目
  - **创作声明（必选）**：所有选项都列给用户，由用户自己选，辰记不预设
  - 定时发布
- 发布前读 `publishLimit`，把今天剩余篇数显示给用户。
