## 官方开放能力（已确认，官方文档）

**网易号开发者平台**支持两种接入角色：

1. **内容网站（内容生产提供方）**：网站自己产内容，在开发者中心绑定自己的网易号后，从自家 CMS 直接发文，同步到网易号。例子是澎湃新闻。
2. **第三方服务平台（第三方内容平台）**：服务自媒体作者，接入后开放给外部作者使用，例子是火星云分发。**网易号作者在第三方平台上授权网易号后，就能直接在第三方平台发文同步。** 辰记属于这一类。

**接入流程**
1. 登录网易通行证。
2. 注册开发者：填写表单，提交资质证明文件，等审核。
3. 创建应用：审核通过前只能建 1 个，通过后最多 3 个。合作方式选「第三方内容平台」。
4. 绑定网易号账号：作者走 OAuth 授权。
5. 按文档对接发文、发视频接口。

**OAuth2 授权**
- 授权：`https://mp.163.com/oauth2/authorize?client_id=…&response_type=code&redirect_uri=…`
- 换令牌：`POST https://mp.163.com/oauth2/access_token?client_id=…&client_secret=…&grant_type=authorization_code&code=…`，返回 `access_token`、`refresh_token`、`expires_in`、`user_id`。
- 续期：`grant_type=refresh_token`，每次续期把过期时间重置为 30 天。`code` 10 分钟内有效。
- 部分错误码：
  - `10004`：用户还没入驻网易号
  - `110011`：应用权限不足
  - `110012` / `110013`：令牌过期或无效

**发文接口**：`POST http://mp.163.com/wemedia/article/status/api/oauth2/publish.do`，用表单提交。

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✔ | **11–30 字** |
| `content` | ✔ | HTML，例如 `<p>…</p>`；图片写成 `<img src="…" contenteditable="false">` |
| `original` | — | `true` / `false`；账号没有原创资质时，按 `false` 处理 |
| `user_classify` | ✔ | 分类名，二级分类用 `/` 分隔，例如 `人文/民俗` |
| `cover` | — | `auto`（默认，从正文里挑一张）/ `custom`（单图 336×210）/ `threeImg`（三图，各 336×210）/ `bigImg`（大图，≥ 750×375，建议 1014×507） |
| `pic_url` | — | `cover` 不是 `auto` 时必传；三图时传 3 个 URL，用英文逗号分隔 |
| `access_token` | ✔ | 用户授权后拿到的令牌 |

返回 `{"code":1, "data":{"docId":"…"}}`。

**其他接口**

| 接口 | 作用 |
|---|---|
| `GET /oauth2/article/category/get.do?client_id&client_secret` | 文章分类（一级 → 二级） |
| `POST /oauth2/article/state/get.do`（`docIds`，用英文逗号分隔） | 发布状态：0 草稿、1 审核中、2 未通过、**3 已发布**、4 处理中、5 处理失败、6 管理员下线、7 作者下线、8 待发布、9 已删除、10 作者删除、11 MCN 主账号下线 |
| `POST /oauth2/article/offline.do` | 下线文章 |
| `POST /wemedia/video/status/api/oauth2/publish.do` | 发视频：标题 11–30 字，标签 3–5 个，封面最小 720×360，视频填可下载的 URL，必选分类 |
| `GET so.v.163.com/ugc/getCategory.do`、`POST /oauth2/video/state/get.do` | 视频分类、视频发布状态 |

**开发者协议里要注意的几条**
- 未经网易书面许可，不能在应用里使用「网易」「网易号」等商标。
- 应用要给权利人提供投诉途径。
- 应用使用者的数据要先取得同意。
- 不能替别的第三方应用代为申请。

## 实测记录

### 2026-10-29（新注册，账号名「辰记」）

- 后台首页提示「**您的账号信息正在审核中，请耐心等待哦**」。用户说明：**需要实名**。
- 后台菜单：
  - 开始创作：文章、视频、动态
  - 管理：内容管理、草稿管理
  - 数据：内容数据、粉丝数据、收益数据
  - 提现
  - 成长指南：**优质内容激励计划**、权益中心、认证中心、创作学院
  - 账号信息
- 首页有「活动广场」，都是有奖活动，奖金 500 到 1000 元。公告里有一条「收益提现门槛下调」。
- 网页编辑器还没看：账号在审核中，等审核通过、实名完成后再看。

## 发布后的数据与变现（⚠️ 待账号审核通过后实测）

- 数据：内容数据、粉丝数据、收益数据。官方 API 只有「发布状态」，**没有阅读数这类数据接口**，所以数据只能从后台页面读。
- 变现：优质内容激励计划、权益中心、活动奖金、提现。

## 辰记要做的

- **首选官方通道**：辰记以「第三方内容平台」身份注册网易号开发者，用户在辰记里点「授权网易号」就能一键发布。
  - 注册开发者要交资质文件、等审核，这一步由辰记团队（陆德俊）去办。
  - 回调地址用 `starnote.app` 的域名。
- 在官方通道下来之前，先做桌面端发布台作过渡，等编辑器实测后再定字段。
- 发文时，标题必须是 11–30 字，太短的要提示用户补；分类从分类接口取；封面优先用 `bigImg`（1014×507）。
