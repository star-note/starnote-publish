# 企鹅号 / 腾讯内容开放平台（qq-om）

调研日期 2026-10-29。资料来源：实测。⚠️ 表示还没实测、没有官方依据。

## 入口

| 项 | 值 |
|---|---|
| 登录 / 注册 | `https://om.qq.com/userAuth/index`，注册页是 `/userReg/register`。注册分四步：注册账号 → 选择主体类型 → 填写账号信息 → 填写管理者信息 |
| 后台 | `https://om.qq.com/main` |
| 写文章 | `/main/creation/article`，同一页还能切到「视频」「视频合辑」 |
| logo | `packages/logos`：`qq-om-64.png` / `qq-om-128.png` |
| 辰记现状 | 只有 logo，注册表里没有这个平台，也没有适配器 |

**分发范围**：页面原文是「在腾讯内容开放平台发布的内容将会在腾讯视频、QQ 浏览器、腾讯新闻、腾讯体育、腾讯微视等腾讯系全平台共享，获取全平台收益」。后台左侧也按这些渠道分开显示内容管理和数据分析：QQ 浏览器（kandian）、腾讯新闻（news）、腾讯微视、腾讯视频（live）、腾讯体育（sports）。

## 「微信注册 / 登录」在内嵌浏览器里点不动（重要）

- 现象：点「微信注册」没有任何反应。控制台反复报「Cannot set properties of null (setting 'location')」。
- 原因：页面的写法是先 `window.open()` 开一个空窗口，再给它的 `location` 赋值。内嵌浏览器会拦截脚本发起的弹窗，`window.open()` 拿到的是 `null`，接下来赋值就报错。
- 实际要打开的地址是微信开放平台的扫码页：`https://open.weixin.qq.com/connect/qrconnect?appid=wx2940959351a738f7&redirect_uri=https://om.qq.com/userReg/doWxRegisterCallback?...&scope=snsapi_login`。在当前标签页直接打开这个地址，扫码后会回到企鹅号，流程能走通（2026-10-29 实测）。
- QQ 登录走的是内嵌的 `graph.qq.com/oauth2.0/authorize` iframe，不受这个问题影响。
- **对辰记桌面端的影响**：发布台的登录窗口要处理 `window.open`。要么在同一个窗口里打开目标地址，要么把返回值换成一个能接收 `location` 赋值的代理窗口，再把那个地址载入当前窗口。不能直接返回 `null`。腾讯系平台的扫码登录很可能都是这种写法。

## 官方开放能力

后台没有看到开发者入口，网上也没搜到公开的发文接口文档。⚠️ 历史上对 MCN 和第三方工具开放过授权接口，现在的状态不清楚。目前只能走桌面端发布台。

## 编辑器与发布字段（实测）

- 正文编辑器是 **ProseMirror**（`.ProseMirror.ExEditor-basic`）。工具栏有：图片、视频、链接、插入、表情、表格、字号、加粗、斜体、标题、下划线、删除线、文字颜色、背景色、列表、对齐、分割线、引用、格式刷、清除格式、查找替换，以及撤销、重做。

| 字段 | 必填 | 说明 |
|---|---|---|
| 标题 | ✔ | 5–64 字 |
| **标题2** | — | 6–35 字。⚠️ 推测是双标题测试，或者是短标题 |
| 摘要 | — | 文本框 |
| 结语 | — | 文本框 |
| 封面 | 选填 | 单图 / 三图 |
| 分类 | 选填 | 列表来自 `/article/categoryList`，会记住常用分类 |
| 标签 | 选填 | **最多 9 个，每个不超过 8 个字**，用空格或回车分隔；有推荐标签，来自 `/marticlepublish/getSpecifiedMediaTags` |
| 活动投稿 | 选填 | 列出正在进行的征文活动，例如「尚公主」征文最高奖 1500 元、「亚运创作征集令」最高奖 2000 元 |
| 自主声明 | 选填 | 「添加内容自主声明」，用于虚构演绎、内容转载等情况 |

- 底部按钮：发布、**定时发布**、存草稿、预览。左下角有「正文字数」统计，旁边有导入按钮（⚠️ 支持哪些文件格式还没看）。
- 右侧有「诊断助手」，会检测作品里的质量问题。

## 风控

- 能读到的 cookie：`csrfToken`、`omaccesstoken`、`omaccesstoken_expire`、`omtoken`、`userid`、`qlogin_uid`、`wxky`、`TSID`。
- 页面接了腾讯云前端监控 `AegisV2`，验证码用的是腾讯防水墙（`captcha.gtimg.com`）。
- 接口路径形如 `/marticle/creation/initInfo`、`/maccountsetting/basicinfo/`、`/editorCache/get`。

## 发布后的数据与变现

- 首页显示累计收入、累计阅读量、累计播放量、粉丝量，以及评论数据。数据入口是 `/main/statistic/article`（图文）、`/video`、`/fans`，各个分发渠道还有各自的数据分析页。
- 变现：
  - **收益分析**（`/main/income/incomeStatistic`）：「流量收益」，新号显示暂无收益。
  - **结算中心**：`/main/income/adSettle`。
  - **权益管理**（`/main/account/rights`）：腾讯新闻的「图文原创」「视频原创」两项都没开通。开通后可以声明原创，并享受一键维权、全网监测。
  - **活动约稿**：征文活动有最高激励。还有面向内容合作伙伴的「百舸争流」「春晓」创作激励计划，在流量分成之外另发奖励。
- 开通门槛（原创、流量分成）待查。

## 辰记要做到的

- 发布台登录窗口要解决 `window.open` 被拦截的问题，见上文。
- 发布台要能填的字段：
  - 标题（5–64 字），标题2（可选）
  - 正文、摘要、结语
  - 封面：单图或三图
  - 分类、标签（最多 9 个，每个 8 字以内）
  - 活动投稿（可选）
  - 自主声明
  - 定时发布
- 发布页要提示用户：一次发布会同步到腾讯新闻、QQ 浏览器等渠道。
